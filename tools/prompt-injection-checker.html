    Common questions
    
      
    What is prompt injection?
    Prompt injection is an attack where text supplied to a large language model (LLM) contains instructions that override or manipulate the developer's intended behaviour. It is ranked LLM01 — the top risk — in the OWASP Top 10 for LLM Applications.
    
      
    What is the difference between direct and indirect prompt injection?
    Direct prompt injection comes from the user typing into the chat. Indirect prompt injection is hidden inside content the model reads on the user's behalf — a web page, PDF, email, support ticket or retrieved RAG document — so the victim never sees the payload.
    
      
    Can this tool guarantee text is safe to send to an LLM?
    No. It is a heuristic scanner that flags known injection patterns, hidden characters and exfiltration tricks. Novel or paraphrased attacks can evade any pattern list, so use it as a triage signal alongside architectural controls such as least-privilege tools, output filtering and human approval for risky actions.
    
      
    Is the text I paste sent anywhere?
    No. All analysis runs locally in your browser with JavaScript. Nothing you paste is uploaded, logged or stored.
    
      
    How do I test my own AI application for prompt injection?
    Build a payload set covering instruction override, role-play jailbreaks, system prompt extraction, indirect injection through documents, and tool-call abuse; run it against every input channel, and verify what the model can actually do when it complies.
