Scam Message Analyzer

Paste a suspicious SMS, WhatsApp, or email message. This checks it against patterns commonly used in phishing, UPI fraud, delivery scams, and impersonation attempts. Nothing is sent anywhere — this runs entirely in your browser.

pattern-match.local — offline
This is pattern-matching, not proof. A message with zero flags can still be a scam, and a legitimate message can occasionally trip a flag. Use this as one signal, not a verdict — never send OTPs, PINs, or payments based on an unsolicited message regardless of what this tool says.
