Email Header Analyzer

Paste the full raw headers of a suspicious email (in Gmail: ⋮ menu → "Show original"; in Outlook: File → Properties → Internet headers). This checks SPF/DKIM/DMARC authentication and shows the server path the email traveled — the same first checks used to spot a spoofed sender. Runs entirely in your browser.

header-parser.local — offline
A passing SPF/DKIM/DMARC doesn't guarantee an email is legitimate — it only confirms the message wasn't forged in transit. A scammer can register a real domain and pass all three. Always verify unexpected requests (payments, credentials, links) through a separate channel.
