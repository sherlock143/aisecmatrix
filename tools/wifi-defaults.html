Wi-Fi Router Default Password Lookup

Look up the out-of-the-box admin login for common router brands. If you've never changed this, anyone on your network — or in some cases, the internet — can log in and reconfigure your router.

router-db.local — offline
These are widely published factory defaults, not secrets — anyone can search them, including attackers. That's exactly the point: if your router still uses one of these, change the admin password today from the router's settings page (not your Wi-Fi password — the admin login to the router itself).
