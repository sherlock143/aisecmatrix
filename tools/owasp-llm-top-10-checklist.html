How to use this LLM security checklist

Work through one category at a time with the people who own the application. For each item, tick it only when you have evidence — a test result, a configuration screenshot or a code reference — not when someone says it is "probably fine". Unticked items become your remediation backlog or your penetration test scope. For the reasoning behind each category, read OWASP LLM Top 10 explained with examples; to test LLM01 hands-on, start with the Prompt Injection Checker and the prompt injection testing guide. Common questions

What is the OWASP Top 10 for LLM Applications?

It is the OWASP project's ranking of the ten most critical security risks in applications built on large language models. The 2025 edition covers Prompt Injection, Sensitive Information Disclosure, Supply Chain, Data and Model Poisoning, Improper Output Handling, Excessive Agency, System Prompt Leakage, Vector and Embedding Weaknesses, Misinformation and Unbounded Consumption.

Who should use this checklist?

Developers, security engineers, penetration testers and product owners building or reviewing chatbots, copilots, RAG applications and AI agents. It works as a pre-launch review, a pentest scoping aid or an audit evidence tracker.

Is my progress saved?

Your ticks are kept only in your own browser on this device, so you can come back later. Nothing is sent to our servers. Use Export to save a Markdown copy.

Does completing the checklist mean my AI app is secure?

No. A checklist confirms controls exist; it does not prove they work against a motivated attacker. Validate the controls with hands-on adversarial testing such as prompt injection, tool-abuse and data-leakage testing.
