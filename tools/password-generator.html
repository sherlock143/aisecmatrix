Why this matters
🎲

True randomness

Uses crypto.getRandomValues(), a cryptographically secure random number generator — the same standard used to generate encryption keys, not a predictable pseudo-random function.

🔒

Never transmitted

Password generation happens entirely in your browser's JavaScript engine. Nothing is sent to any server — not even to us.

🎯

Guaranteed character coverage

If you select multiple character types, the generator guarantees at least one of each appears — no risk of a "strong" password that's secretly all letters.
