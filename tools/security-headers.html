Security Headers Scanner

Enter any website's address to check the HTTP security headers it sends. These are checks run early in almost every professional web penetration test — missing headers don't guarantee a site is unsafe, but they're a quick signal of how seriously it's configured.

headers-scan.aisecmatrix.com
Only scan sites you own or have permission to test. This tool makes a single standard GET request server-side (the same as visiting the page in a browser) to read its public response headers — it does not probe, exploit, or brute-force anything.
